How a candle is made

Pour

Wax goes into the mould while it is still warm, so the surface sets smooth.

Trim

Each wick is cut to a fixed length before the first light, so every burn starts even.

Cure

Each candle rests for two weeks, so the scent settles into the wax before it is packed.

Light

Let the first burn reach the edge of the jar. That keeps every burn after it even.
